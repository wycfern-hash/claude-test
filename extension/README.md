# 蝦皮特賣分潤小幫手（Chrome 擴充功能）

抓蝦皮**限時特賣**的所有商品、也能搜尋**不在限時特賣裡的其他特價商品**；每個商品都顯示
**場次日期與時間**、**開始特價了沒／距離開始還有多久**；再用你登入的分潤後台一鍵轉成**分潤連結**，最後匯出 CSV。

不需要安裝 Python，也不用蝦皮 API。

## 安裝（1 分鐘，只要做一次）

1. 下載整個專案並解壓縮（專案 ZIP：<https://github.com/wycfern-hash/claude-test/archive/refs/heads/claude/gallant-hypatia-vttt55.zip>）。
2. 打開 Chrome，網址列輸入 `chrome://extensions` 按 Enter。
3. 右上角把「**開發人員模式**」打開。
4. 左上角按「**載入未封裝項目**」，選專案裡的 **`extension`** 資料夾（裡面有 `manifest.json` 的那個）。
5. 看到「蝦皮特賣分潤小幫手」出現就成功。點網址列右邊的拼圖圖示 → 圖釘，把它釘起來。

> 需要 Chrome 111 以上。之後更新程式碼，只要在 `chrome://extensions` 按該擴充功能的「重新載入」圓圈。

## 使用（照畫面上的 ①②③）

先在**同一個 Chrome** 登入蝦皮（[shopee.tw](https://shopee.tw)）和分潤後台（[affiliate.shopee.tw](https://affiliate.shopee.tw)）。點工具列的小幫手圖示開啟畫面：

1. **① 抓商品**
   - 限時特賣：貼上限時特賣網址（已經預填你給的那個；**一行一個場次**），按「開始抓取限時特賣」。會開一個新視窗**自動往下捲動**把商品全部讀出來，**請不要關掉**，好了會自動關閉；畫面會逐個場次回報進度，**「停止」按鈕隨時可以中斷**。要抓別的場次：在蝦皮點那個場次，把網址複製貼進來（一行一個）。同一個場次不會抓第二次。
   - 「自動再找後面的場次」是**實驗性**（預設 0 = 關）：蝦皮有時會把場次網址轉到首頁，轉走的場次會自動跳過，**不會收首頁的資料**。
   - 小幫手**只收「限時特賣頁」和「搜尋頁」本身的資料**，蝦皮首頁等其他頁面的限時特賣小區塊一律不收。
   - 其他特價商品：輸入關鍵字、頁數、折扣門檻，按「搜尋特價商品」。結果會自動排除已經在限時特賣裡的。
2. **② 轉成分潤連結**：按「把目前列表轉成分潤連結」，會開分潤後台視窗自動轉。沒轉成功的會標示原因。**還沒轉的商品會明確標示「尚未轉換（還不是分潤連結）」**，不會把一般連結當成分潤連結。
   - **想一次轉很多個（不要一個一個轉）：** 先按「**學習後台做法：我先手動轉 1 個**」，在跳出的分潤後台貼任一個商品連結、按「取得連結」。小幫手會記下你的後台真正送出的請求格式（只記有回傳短連結的那一個請求，標頭只留 3 個，不記帳號密碼），之後照同樣格式**一次送一大批**；後台不收就自動減量（20 → 10 → 5 → 1）。只要做一次，清空資料也會保留。
   - 如果學到的結果是「**這個後台一次只能轉 1 個**」，就沒辦法一個請求轉全部，但小幫手會**同時送出 4 個請求**（不用一個等一個），後台嫌太快（限流）就自動減速重試。
   - 沒學習時會用內建的格式猜，猜不中才退回「一個一個模擬操作」（最慢）。畫面上會寫這次是用哪一種：**「一次最多轉 N 個」＝批次**；**「同時送出 N 個請求」＝後台只收 1 個、但同時送**；**「一個一個轉」＝最慢的備援**。
3. **③ 匯出**：「匯出 CSV」或「複製文案」。CSV 的欄位可以直接匯入「蝦皮短影音自動化」程式（欄位：商品名稱、商品連結、分潤連結、價格、原價、折扣、場次開始、場次結束、狀態、庫存、已售、圖片連結）。

畫面上每個限時特賣商品都會寫清楚，例如：

```
2026/10/07（週三） 12:00 – 14:00
🔥 已開始・剩 01:23:10          ← 已經開始特價，倒數到結束
⏳ 距離開始 02:15:30            ← 還沒開始，倒數到開始
已結束
```

時間一律用台北時間，每秒自動更新。可以用上方的「狀態」篩選只看已開始／尚未開始。

## 分潤連結是怎麼來的（重要）

**分潤連結一定是透過你的瀏覽器、到你登入的分潤後台取得的，程式不會自己拼或亂給連結。**

1. 小幫手開一個 `affiliate.shopee.tw` 的視窗，用的是你這個 Chrome 登入的分潤帳號。
2. 把商品網址交給後台的「自訂連結」功能，後台回傳 `https://s.shopee.tw/xxxx` 短連結，這個連結已經綁了你的分潤身分。
3. 沒轉成功的商品，分潤連結欄是**空的**，並標示「尚未轉換（不是分潤連結）」，匯出的 CSV 也一樣。
4. 匯入「蝦皮短影音自動化」後，**沒有分潤連結的商品預設不會上架**（不會悄悄改用一般連結）；之後把轉好的 CSV 重新匯入，會自動補上分潤連結。

連結算在誰名下，取決於這個 Chrome 登入的是哪個分潤帳號，請先確認。

## 它是怎麼取得資料的

不會自己去呼叫蝦皮的 API（那樣會被擋）。它只是在你自己的 Chrome 打開蝦皮頁面時，**複製頁面本來就在載入的商品資料**，所以用的是你自己的登入狀態，看到什麼就讀什麼。

## 還沒驗證的部分（請先讀這段）

我的開發環境連不到蝦皮，所以：

- 我用「依蝦皮公開流傳的資料格式做的假網站」在真的 Chrome 裡完整跑過上面所有流程（分批載入、多場次、搜尋、轉分潤、匯出），也寫了各種資料格式的測試。**但沒有在真的蝦皮頁面上跑過**，蝦皮實際的資料欄位、分潤後台的實際介面可能和我預期不同。
- **轉分潤連結**有兩條路：先試分潤後台自己的批次轉換；不行就改成模擬「在自訂連結頁貼商品連結、按取得連結」。分潤後台改版時這兩條都可能失效。
- 如果抓不到東西或轉換失敗：按畫面上的「**下載診斷檔**」，把檔案傳給我，裡面有最近收到的資料樣本，我就能對照真實格式修正。

## 注意

- 蝦皮可能要求登入、跳出驗證或限制頻繁操作。這個工具只是模擬你自己在瀏覽，請維持合理的量，不要一次抓太多、轉太多。
- 自動操作蝦皮網頁可能違反平台規範，請自行評估風險。
